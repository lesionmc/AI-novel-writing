## 要求

1. 按下列类别找问题，**只报客观问题**，不评价文笔好坏、不评价情节是否精彩：
   - `typo`　　错别字、明显的用词错误
   - `punctuation`　标点误用（中英标点混用、引号不配对、省略号写成六个点等）
   - `grammar`　　病句、成分残缺、语序不当
   - `name`　　　人名/地名/称呼前后不一致（**这是"吃书"最直接的信号**）
   - `setting`　　与上方设定库或人物现状冲突（如已死角色出场、能力等级对不上）
   - `repeat`　　同章内明显的重复表达
2. 每条必须给出：
   - `type`：上面的类别之一
   - `excerpt`：**原文里逐字摘出来的片段**（必须能在上方「待校对文本」里搜到，不要改写它）
   - `problem`：一句话说清问题是什么
   - `suggestion`：怎么改（**说明性的建议**，例如「改为『他径直走向门口』」，不要整段重写）
3. 没有问题的类别就不用报。**如果通篇没有可报的问题，返回空数组** ——
   不要为了凑数把正常表达说成问题。
4. 最多报 12 条，按严重程度从高到低排。

## 输出格式

只输出 JSON：

{
  "issues": [
    { "type": "typo", "excerpt": "...", "problem": "...", "suggestion": "..." }
  ]
}
