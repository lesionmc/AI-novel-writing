## 要求

1. 给出 {{count}} 条**互不相同**的走向，每条都要接得住上面的现状与未回收伏笔。
2. 每条包含四个字段：
   - `title`：一句话说清「这一步发生什么」，不超过 20 字
   - `summary`：2–3 句展开，说清冲突是什么、谁跟谁对立
   - `payoff`：这条走向兑现了什么（回收哪条伏笔 / 给读者什么爽点）
   - `risk`：这条走向的代价（如「节奏会慢一章」「某个角色会提前退场」）
3. **只给方向。不要写任何正文段落、对话或具体台词。**
4. 至少有 1 条要**优先回收埋得最久、重要度最高的那条伏笔**。
5. 禁止「主角突然变强」「反派突然降智」这类没有铺垫的廉价走向。
6. 四条方向之间要有**实质差异**（不同对手 / 不同代价 / 不同节奏），不要换个说法重复同一条。

## 输出格式

只输出 JSON：

{
  "directions": [
    { "title": "...", "summary": "...", "payoff": "...", "risk": "..." }
  ]
}
