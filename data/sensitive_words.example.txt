# 敏感词库格式示例文件
# ============================================================
# 用法：把本文件复制为 data/sensitive_words.txt，然后替换成你自己的词表。
#
# 格式规则：
#   · 以 # 开头的行是注释，会被忽略
#   · 空行会被忽略
#   · 每行一个词条，格式：词条[,分类]
#   · 分类可省略，省略时归入「其他」
#
# 可用分类：
#   politics     政治敏感
#   violence     暴力血腥
#   porn         色情低俗
#   illegal      违法违规
#   superstition 封建迷信
#   other        其他
#
# 支持变体写法：用 | 分隔同一词条的不同写法，全部纳入匹配
#   示例：敏感词A|敏感词A变体|敏感词A拼音
#
# ⚠️ 本示例文件不含任何真实敏感词，仅为格式演示。
#    实际词库需由使用者自行准备，来源建议见《11-敏感词库说明.md》第 3.3 节。
# ============================================================
