## 二、验收用例（`07` 36 条）覆盖核对结论

逐条核对 `06` 端点支撑能力：**36 条 TC 全部可被 `06` 端点支撑**，但前提是先补 `D-05`（outline expand）与 `D-06`（provider usage）两条。重点：

- TC-04/05/06 书库 → `06` books；TC-07/08/09/10 设定 → `06` settings + affected-chapters。
- TC-11/12/13 编辑器 → `06` chapters（列表无正文，TC-13 通过）。
- TC-14 版本 → `06` versions/restore；TC-15/16/17 导出 → `06` export。
- TC-18 全功能无模型可用 → 端点均不强制模型；TC-19 无模型结构化召回 → `recall` 结构化路（坑 8）。
- TC-20/21/22/23 providers → `06`（TC-23 依赖 `task_role` 路由）。
- TC-24/25/26/27 回写 → `06` finalize/confirm（TC-26 注意坑 6）。
- TC-28～33 召回 → `06` recall + recall-logs（TC-32 需 `structured_hits`/`semantic_hits`，见 D-08）。
- TC-34 性能、TC-35 外键级联（`05` 已 `ON DELETE CASCADE`）、TC-36 备份恢复（ADR-001）。
